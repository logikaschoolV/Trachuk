# LogikTalk 

**LogikTalk** - це простий і зручний чат з підтримкою обміну повідомлення та зображенням в реальному часі.
побудований на Python, tkinter/CustomTkinter і сокетах.
## Можливості 
  -Надсилання текстових повідомлень у реальному часі
  -передача зображень (jpg, png, тощо)
  -підтримка кількох користувачів
  -Авторизація (ім'я користувача)
  -простий та інтуївний інтерфейс

  ## Використання технології 
    -Python 3 
    -[CustomTkinter]
    -socket
    -base64 (для передачі зображеня)
    -pillow (PIL) для обробки зображень
